UK · YLB Studio

Each style takes the brand somewhere different. They share the same wordmark text and the same palette (paper / ink / red), but the personality changes hard between them. Look at each as if you were introducing yourself as it. No favourites — just say which direction feels right and we go deeper on that one.

Style 01
Editorial Black
SERIF · MASTHEAD

Magazine masthead energy. Heavy display serif, fine hairline rule, mono caption. Reads as old-money and considered. Pairs well with a restrained editorial site — long-form case studies, sober photography, lots of white space. Strength · Earned · Trustworthy

Style 02
Modern Lowercase
SANS · TECH

Linear / Vercel / Stripe energy. Lowercase, geometric, tight letterspacing, red period as a single brand accent. Says "we are technology people who ship." Works best in dark mode, but reads cleanly on light too. Modern · Tech-fluent · Quietly confident

Style 03
Stamp / Seal
CIRCULAR · MARK-LED

Notary stamp / passport mark. A circular seal you stamp on every proposal, invoice, and case study. Plays the brand as "approved, official, on the record." Has personality — would absolutely turn heads on LinkedIn. Risk: tips cute if not executed restrained. Distinctive · Memorable · Slightly nostalgic

Style 04
Mark + Wordmark
GRAPHIC SYSTEM

Classic identity system. Custom graphic mark (the "booked" appointment slot — one row filled red in a stack of empty ones) plus the wordmark. The mark works at every size, scales down to a favicon perfectly. Most timeless of the five. Most flexible for use everywhere. Considered · Scalable · Brand-system-ready

Style 05
Bracket / Code
SYSTEM NOTATION

Code / system aesthetic. Red brackets bookend the wordmark; a comment-style metadata caption beneath. Signals "engineers, developers, AI builders" — perfect if you want prospects to immediately read you as technical / shippers. Most differentiated of the five from typical agency naming. Engineered · Bold · Developer-friendly

Pick a direction

Reply with the style number (01–05). I'll generate a tighter set of variants in your chosen direction, lock the wordmark, and ship it into the brand config + header + favicon + site.
